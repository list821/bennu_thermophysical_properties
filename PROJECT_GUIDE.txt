BENNU ATPM 项目说明
===================

一、项目现在保留的目标
----------------------

本项目只保留一条正式流程：

2018-11-02/03 OVIRS L2 v2 FITS
  -> 质量筛选
  -> 在 2.05–2.15 um 缩放太阳谱
  -> 从 3.98–4.02 um 辐亮度中扣除反射太阳光
  -> 按 Bennu 自转相位每 1 度分箱
  -> 用 SPICE 计算逐帧太阳、航天器、OVIRS 视轴和 FOV
  -> SPCv14 三角形形状上的 ATPM 正演
  -> 扫描热惯量 Gamma 并计算 chi-square
  -> 输出最佳值、表格和补充图 2b 风格曲线。

旧的代理数据反演、旧 OTES 归一化反演、Julia 示例、重复 SPICE 核和旧调试输出
已经删除，以免同一项目出现多个互不等价的入口。


二、目录和代码之间的关系
------------------------

reproduce_supplementary_fig2b.py
  唯一正式入口。组织读取、逐帧处理、SPICE、1 度分箱、ATPM 网格和 chi-square。

pds_observations.py
  读取 OVIRS FITS/XML；返回 20×512 的辐亮度、波长、不确定度和质量数组；执行
  2.1 um 太阳谱定标及 4 um 反射光扣除。

spice_geometry.py
  装载 CK/IK/SPK/PCK/FK/SCLK/LSK，在每个 FITS 的 UTC 时刻把太阳、航天器和
  OVIRS 视轴转换到 IAU_BENNU 天体固定坐标系。

bennu_atpm.py
  热物理正演核心：OBJ 三角面元、周期稳态一维导热、90 度半球坑、ACF、坑口
  可见性、多次太阳散射、坑壁自加热、Planck 辐射、OVIRS 通道近似卷积、孔径
  响应以及式(24)光滑/粗糙混合。

shape_radiation.py
  bennu_atpm.py 在开启全局遮挡/互热时调用。使用 Embree 射线判断宏观面元遮挡，
  并构造稀疏全局视因子。

download_ovirs_20181102_03.py
  从 PDS 下载两天共 34,254 个真实 OVIRS FITS，支持续传、大小和 FITS 签名检查。

download_spice_kernels.py
  下载当前流程所需的官方 NAIF kernels。

inspect_inputs.py
  不修改数据，只显示一个 FITS 的数组形状、单位、4 um 提取值、太阳谱范围、
  OBJ 顶点/面元数、SPICE 文件完整性和逐帧缓存字段。

crater_resolution_convergence.py
  比较 8、18、32、72、128、200 个坑壁单元的 4 um 曲线，检查粗糙坑网格收敛。

test_bennu_atpm.py、test_pds_observations.py
  检查 Planck 函数、导热正演、ACF、式(24)、局部坐标、坑口射线和 OVIRS 格式。


三、输入数据在哪里，以及每个数据是什么
----------------------------------------

1. data/ovirs/full/*.fits

真实主输入，共 34,254 帧。文件名格式为：

20181102T041236S859_ovr_scil2_calv2.fits

20181102 是日期，T041236 是 UTC 时分秒，S859 是毫秒，ovr_scil2_calv2 表示
OVIRS science level-2 calibrated version 2。

每个 FITS 在本项目中按官方固定布局读取：

primary header：观测时间等元数据；
radiance：20×512，大端 float64，单位 W cm^-2 um^-1 sr^-1；
quality：20×512，大端 int32，每个值是质量位掩码；
wavelength_um：20×512，大端 float64，单位 um；
uncertainty：20×512，大端 float64，与 radiance 同单位。

20 行代表空间/超像素样本，512 列代表光谱通道。每一格必须用同位置的 wavelength
解释波长，用 quality 判断是否可用，用 uncertainty 作为误差。

对应 XML（若存在）提供：

mid_obs：曝光中点 UTC；
bore_flag：视轴状态；
fov_fill_factor：Bennu 占 FOV 的比例；
phase_angle：太阳—Bennu—观测者相角；
sun_range：日心距离；
target_range：航天器到 Bennu 的距离。

重要：FILL_FAC 在当前流程只保留为诊断量。L2 radiance 已经是辐亮度口径，不能
再除以约 0.37，否则会把约 1.05 的量级放大到约 2.8–3.0。

2. data/ovirs/orexsolarflux.csv

共四列：第 1 列是波长 um；第 2 列是光谱能量密度 W m^-2 nm^-1；第 3 列是同单位
不确定度；第 4 列是 lambda/delta-lambda FWHM 平滑分辨率。当前反射扣除使用前两列，
把太阳谱插值到每个 OVIRS 波长，在 2.05–2.15 um 拟合缩放系数，再从
3.98–4.02 um 的测量辐亮度中减去缩放后的太阳反射分量。

3. data/shape/g_12560mm_spc_obj_0000n00000_v014.obj

公开 SPCv14、约 12.56 m 分辨率的 Bennu 形状。OBJ 文本中：

v x y z        表示一个三维顶点；
f i j k        表示由第 i、j、k 个顶点构成的三角面元。

PDS 顶点坐标单位是 km，load_obj() 会自动转为 m，然后计算面心、外法向和 m^2
面积。它不是论文作者使用的 SPCv13，这是严格复现仍存在的输入差异。

4. D:\ATPM\data\spice\kernels

Windows CSPICE 对含中文路径可能不稳定，所以当前默认使用 ASCII 联接 D:\ATPM。
该位置应指向 D:\ChatGPT\热物理反演。

kernel 类型及含义：

LSK：闰秒，把 UTC 转换为 SPICE ET；
SCLK：OSIRIS-REx 航天器时钟转换；
SPK：太阳、Bennu、航天器的位置和距离；
PCK：Bennu 自转和天体固定坐标；
FK：航天器、形状和仪器坐标系定义；
CK：逐时刻航天器姿态；
IK：OVIRS 视轴、圆形 FOV 和边缘方向。

5. 模型参数

ThermoConfig 位于 bennu_atpm.py。主要输入为：

period_hours=4.296061 h；Bond albedo=0.016；emissivity=0.9；
坑壁网格=8×16=128；粗糙坑覆盖率在主程序固定为 0.77；
OVIRS 中心波长=4.00038 um；近似 FWHM=0.00641 um。

命令行的 gamma-min、gamma-max、gamma-step 决定热惯量扫描范围；model-phases
决定一个自转周期的时间采样；fit-facet-stride 决定 Gamma 扫描使用多少形状面元。


四、怎么看实际数据格式
----------------------

在项目根目录运行：

  .\.venv\Scripts\python.exe .\inspect_inputs.py

它会打印一个真实 OVIRS 样本的四个 20×512 数组、单位、观测时间、FILL_FAC、
扣反射后的 4 um 值、OBJ 网格统计、SPICE 缺失文件和缓存 CSV 字段。

查看 PDS XML 可直接在 VS Code 打开对应 .xml。查看 OBJ 也可直接打开；文件较大时
建议只预览开头。CSV 可在 VS Code 或 Excel 打开，JSON 可在 VS Code 折叠查看。


五、首次安装与数据下载
----------------------

在 PowerShell 进入：

  Set-Location 'D:\ChatGPT\热物理反演'

创建环境并安装依赖：

  py -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r .\requirements.txt

如果 D:\ATPM 尚不存在，创建 ASCII 路径联接：

  New-Item -ItemType Junction -Path 'D:\ATPM' -Target 'D:\ChatGPT\热物理反演'

下载 OVIRS 全量数据（约 19 GB）：

  .\.venv\Scripts\python.exe .\download_ovirs_20181102_03.py --output .\data\ovirs\full

下载 SPICE：

  .\.venv\Scripts\python.exe .\download_spice_kernels.py --output 'D:\ATPM\data\spice\kernels'

下载器会跳过已经验证的文件，所以可安全重跑。当前电脑上的完整数据已存在，无需
重复下载。


六、测试和运行完整流程
----------------------

先运行测试：

  .\.venv\Scripts\python.exe -m unittest -v

正式运行：

  .\.venv\Scripts\python.exe -u .\reproduce_supplementary_fig2b.py `
    --input .\data\ovirs\full `
    --shape .\data\shape\g_12560mm_spc_obj_0000n00000_v014.obj `
    --spice-kernels 'D:\ATPM\data\spice\kernels' `
    --output .\output\new_run `
    --gamma-min 0 --gamma-max 600 --gamma-step 10 `
    --model-phases 64 --fit-facet-stride 16

这是高计算量任务。先做功能检查可使用：

  .\.venv\Scripts\python.exe -u .\reproduce_supplementary_fig2b.py `
    --input .\data\ovirs\full `
    --shape .\data\shape\g_12560mm_spc_obj_0000n00000_v014.obj `
    --spice-kernels 'D:\ATPM\data\spice\kernels' `
    --output .\output\smoke_test `
    --gamma-min 180 --gamma-max 188 --gamma-step 2 `
    --model-phases 48 --fit-facet-stride 128 --skip-figure

不要把功能检查输出到 output/supplementary_fig2b，否则会覆盖当前保留的正式结果。


七、程序内部运行顺序
--------------------

1. process_frames() 找到两天 FITS。
2. read_ovirs_product() 读取 20×512 数组和 XML/FITS 头元数据。
3. extract_ovirs_thermal_band() 做质量筛选、太阳谱缩放和反射扣除。
4. attach_spice_geometry() 根据每帧 UTC 计算真实方向、距离、视轴和 FOV。
5. bin_one_degree() 以 4.296061 h 周期分成 360 个转相位箱。
6. load_obj() 读取 SPCv14，计算三角形面心、法向和面积。
7. sampled_mesh() 为 Gamma 网格按 stride 抽样宏观面元。
8. fit_gamma() 对每个 Gamma 调用 simulate()。
9. simulate() 计算光滑端元和全半球坑端元的温度及 4 um 辐射。
10. mixed_detector(0.77) 按式(24)混合两个端元，并通过 OVIRS 孔径响应积分。
11. 模型与两天一度分箱辐亮度比较，求 chi-square 最小的 Gamma。
12. 保存表格、summary.json 和 SVG。


八、输出文件怎么看
------------------

每次运行的 --output 目录包含：

processed_ovirs_frames.csv
  每个 FITS 一行。重点字段：UTC、thermal_radiance、sigma、FILL_FAC、太阳/观测者
  单位向量、日心距、航天器距离、视轴、FOV 半角。它也是下次运行的处理缓存。

ovirs_thermal_1deg.csv
  每个日期每一度相位一行。value 是检测器热辐亮度，sigma 是拟合误差，count 是
  该相位箱包含的原始帧数。

ovirs_gamma_phase_chi2.csv
  thermal_inertia、phase_shift、chi2。使用 SPICE 时 phase_shift 固定为 0。
  chi2 最小行给出当前模型的最佳热惯量。

summary.json
  输入数量、形状来源、坑壁分辨率、SPICE 设置、最佳 Gamma、chi-square、论文参考值
  和限制说明。当前保留结果约为 Gamma=184，但 reduced chi-square 约 433，说明它
  仍不是论文 350±20 的统计等价复现。

supplementary_figure_2b_reproduction.svg
  蓝点是一度分箱 OVIRS 4 um 热辐亮度；三条模型线对应 Gamma=330、350、370。


九、当前结果与论文仍不同的原因
------------------------------

1. 公开的是 L2 v2，不是作者内部 L3a 和其精确欠填充 FOV 校正。
2. 当前反演用 3.98–4.02 um 单光变，论文用 3.5–4.0 um 完整光谱。
3. 当前形状为 SPCv14，论文为 SPCv13。
4. Gamma 扫描为了运行时间会抽样全局形状面元；stride 越小越接近完整形状。
5. 公开 IK 和高斯光谱线形只能近似作者的完整仪器响应。
6. 坑内散射和自加热已实现，但粗糙坑与全局宏观互热还不是完全耦合求解。

这些限制改变光变绝对值、振幅和相位滞后，因而会移动最佳热惯量。当前 90 度半球坑
的 ACF、局部坐标和式(24)已经通过守恒测试，不应再额外乘 ACF。
